## Cara Menghubungkan ke GitHub

Jalankan dari folder project:

```powershell
cd "D:\Self Project\Salut-Cek-Pembayaran"
git branch -M main
git remote add origin https://github.com/mtijan/Salut-Cek-Pembayaran.git
git add README.md
git commit -m "docs: add initial README"
git push -u origin main
```

Jika remote `origin` sudah ada:

```powershell
git remote set-url origin https://github.com/mtijan/Salut-Cek-Pembayaran.git
git push -u origin main
```
